# 个人中心编辑页工具栏图标设计

## 目标

将个人中心内带保存行为的编辑页面统一为运营小家现有的圆形图标工具栏。

## 范围

- 编辑个人资料。
- 修改家庭名称。

邀请成员页只有关闭操作，删除成员使用系统确认弹窗，均不在本次范围内。

## 设计

- 取消使用 `xmark.circle.fill`。
- 保存使用 `checkmark.circle.fill`。
- 两者均为 `24pt semibold`，使用应用绿色。
- 保留“取消”和“保存”的无障碍标签。
- 保留原有保存中、名称必填和异步提交禁用逻辑。

## 验收

- 两个编辑页面不再显示“取消”“保存”文字。
- 图标尺寸、颜色与空间、物品、提醒表单一致。
- 保存和取消行为、禁用状态及错误提示无回归。

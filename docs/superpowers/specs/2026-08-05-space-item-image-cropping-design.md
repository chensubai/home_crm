# 空间与物品图片裁剪设计

## 目标

空间和物品图片在客户端裁剪并压缩后再上传。空间图统一使用 4:3 横向比例，物品图使用 1:1；两类上传 JPEG 均不超过 500KB。

## 范围

- 空间与物品编辑页统一使用头像同样的底部“相册 / 拍照”来源面板。
- 选择或拍摄完成后进入可平移、双指缩放的裁剪页。
- 裁剪框固定居中；图片不能缩小到露出裁剪框背景。
- 点击裁剪页“使用”仅更新当前表单的待保存图片；仍由空间或物品原有保存按钮上传。
- 空间首页卡片封面统一为 4:3，以匹配空间裁剪比例。

## 组件设计

新增一个共享的 `ImageCropInputView`，由调用方传入：

- `aspectRatio`：空间为 `4 / 3`，物品为 `1`。
- `imageData` 和已有远程图片 URL。
- 裁剪标题与预览形状（空间为圆角矩形，物品为圆角正方形）。

组件内部负责来源面板、单张相册选择、相机拍摄、图片读取回退、裁剪、JPEG 压缩和错误提示。压缩逻辑复用现有图片处理器，并统一限制为 512,000 字节。

## 裁剪交互

裁剪画布为黑色，只有居中的固定比例裁剪框透出图片。图片在框内支持拖动与双指缩放；最小缩放为完整覆盖裁剪框。点击“使用”得到准确比例的图片，再交给表单保存。

## 验证

- 单元测试验证 4:3 和 1:1 裁剪结果的比例。
- 单元测试验证压缩结果不超过 500KB。
- 手动验证相册、相机、裁剪、取消、重新选图和原有保存提交流程。

# 空间物品列表风格统一设计

## 目标

让用户从空间卡片进入物品列表后，页面继续沿用运营小家现有的浅色背景、玻璃圆形按钮和白色卡片语言，避免系统默认导航栏与白色列表造成视觉断层。

## 设计

- 隐藏系统导航栏，使用页面内自定义顶部栏。
- 返回按钮使用 `chevron.left`，添加按钮使用 `plus`，两者均放入 `42×42` 白色玻璃圆形按钮。
- 顶部中间展示空间名称；下方展示位置和物品种类数。
- 页面使用 `OnboardingBackground`。
- 有物品时继续使用 `List`，隐藏默认背景和分隔线，将每个物品行绘制为白色半透明卡片。
- 无物品时使用现有 `EmptyStateView`，提供添加物品入口的明确语义。
- 数量减少和增加按钮改为圆形图标按钮。

## 交互约束

- 返回按钮仍调用当前页面的 `dismiss()`。
- 添加按钮仍打开现有 `ItemFormView`，并预选当前空间。
- 点击物品卡片仍打开编辑表单。
- 左滑删除、库存数量调整、错误提示保持现有逻辑。
- 不修改 API、数据模型、同步或图片上传逻辑。

## 验收

- 页面不再出现系统白色导航栏和大面积纯白背景。
- 返回与添加按钮和首页操作按钮风格一致。
- 空列表展示完整空状态，不再是空白页面。
- 物品卡片、状态、数量和加减按钮在 iPhone 16 Pro 尺寸下不重叠。
- 编辑、添加、返回、左滑删除和数量调整入口保持可用。

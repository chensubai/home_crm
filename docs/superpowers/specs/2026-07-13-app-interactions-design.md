# 运营小家 App 交互补全设计

## 目标

让当前 App 中已经展示给用户的主要入口都具备真实业务能力，补齐个人资料、家庭成员、空间、物品和提醒的查看、编辑、启停与删除闭环，并保持现有 iOS 原生玻璃风格。

## 已确认问题

- 个人中心的“家庭信息”和“成员管理”是普通展示视图，没有导航或点击动作。
- `SessionStore` 只持久化 token 和家庭 ID，App 重启后用户昵称、手机号丢失并显示占位内容。
- 提醒开关使用常量绑定并被禁用，提醒行也没有编辑入口。
- 空间和物品表单只有新增模式，iOS 未调用后端已有的更新、删除接口。
- 家庭资料修改、成员移除、个人资料修改和提醒启停缺少后端接口或字段。

## 功能范围

### 空间

- 点击空间卡片仍进入该空间的物品列表。
- 每张空间卡片增加独立的更多菜单，提供“编辑”和“删除”。
- 空间编辑复用现有表单，预填名称、位置、NFC UID 和当前封面；未选择新图片时保留原图。
- 删除前弹出确认框。空间内仍有未删除物品时，服务端拒绝删除并提示先移动或删除物品，避免产生无有效空间的物品。

### 物品

- 点击物品行进入编辑表单。
- 编辑支持名称、空间、状态、分类、数量、单位、条码和图片。
- 保留现有数量加减按钮；服务端返回后以服务端数量覆盖本地乐观更新。
- 物品列表支持左滑删除，并在删除前确认。

### 提醒

- 点击提醒行进入编辑表单，复用新增提醒的日期、时间和重复规则控件。
- 开关代表提醒是否启用，不代表完成状态。
- 新增 `reminders.is_enabled`，默认开启。关闭后保留提醒记录并取消对应本地通知；重新开启后按规则重新注册通知。
- 保留左滑删除；删除或编辑提醒时同步取消旧通知，保存后根据启用状态重新注册。

### 个人资料

- 个人中心头像区域和昵称行可进入资料编辑页。
- 支持修改昵称、从相册选择头像或拍照；图片继续使用现有压缩逻辑，上传前不超过 5 MB。
- `SessionStore` 缓存完整用户信息，并在已登录启动时通过服务端刷新，避免 App 重启后显示占位内容。

### 家庭与成员

- “家庭信息”和“成员管理”进入同一个家庭详情页，展示家庭名称、当前用户角色和成员列表。
- Owner 可以修改家庭名称、生成邀请、移除普通成员。
- 普通成员只读，不展示修改名称、邀请和移除入口。
- Owner 不能移除自己，MVP 不处理所有权转让。
- 邀请页输入可选手机号，创建成功后展示邀请码及有效期。

## 后端接口与数据

- `GET /api/auth/me`：返回当前登录用户。
- `PATCH /api/profile`：修改昵称；头像上传使用 `POST /api/profile` 加 `_method=PATCH` 的 multipart 请求。
- `PATCH /api/families/{family}`：Owner 修改家庭名称。
- `GET /api/families/{family}/members`：沿用现有接口，响应规范化为成员 ID、用户 ID、昵称、手机号和角色。
- `DELETE /api/families/{family}/members/{member}`：Owner 移除普通成员。
- `POST /api/families/{family}/invites`：沿用现有邀请接口。
- `PATCH /api/spaces/{space}`、`DELETE /api/spaces/{space}`：沿用资源接口；带图片更新使用 method spoofing。
- `PATCH /api/items/{item}`、`DELETE /api/items/{item}`：沿用资源接口；带图片更新使用 method spoofing。
- `PATCH /api/reminders/{reminder}`：沿用资源接口并支持 `is_enabled`。

新增字段必须带字段备注，并同步维护现有表备注迁移：

- `users.avatar_key`、`users.avatar_url`、`users.avatar_hash`，均可为空。
- `reminders.is_enabled`，布尔类型，默认 `true`。

家庭列表响应增加当前用户的 `role`，iOS 不再从界面文案猜测权限。

## iOS 数据流

1. 用户点击编辑入口，表单使用现有本地记录预填。
2. 保存时调用对应 API；有新图片时发送 multipart，否则发送 JSON。
3. API 成功后立即用 DTO 更新 SwiftData 对象，再执行当前家庭的增量拉取。
4. API 失败时保留原数据并在当前页面显示中文错误，不关闭表单。
5. 提醒更新额外执行通知取消与重新注册，通知标识继续使用提醒远端 ID。

## 权限与错误处理

- 所有家庭数据继续通过 `AuthorizesFamilyAccess` 做家庭隔离。
- 家庭名称修改、邀请和成员移除要求 `owner` 角色，普通成员访问返回 403。
- 删除空间时检查未删除物品并返回 422 的明确提示。
- 删除成员时校验成员属于当前家庭，禁止移除 Owner。
- 图片上传失败沿用当前七牛云错误响应，不覆盖旧图片。

## 验收标准

- 个人中心所有带箭头的行均可点击，重启 App 后昵称和手机号仍正确。
- Owner 能修改家庭名称、邀请和移除普通成员；Member 只能查看。
- 空间可编辑名称、位置和图片，可删除空空间，非空空间删除会得到明确提示。
- 物品行可编辑全部已展示字段、切换空间和图片，并可左滑删除。
- 提醒行可编辑；开关可实际启停本地通知；编辑、关闭和删除不会留下旧通知。
- 后端功能测试通过，iOS 工程无签名构建通过，并在模拟器逐项点击完成验收。

## 非目标

- 本轮不实现家庭所有权转让。
- 本轮不实现 APNs 服务端推送。
- 本轮不扩展 NFC 实际扫描流程或语音录入。
- 本轮不重构现有视觉系统和底部标签栏。
